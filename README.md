# Scripts

This project is just a few rando scripts I made when I was learning batch.

|Script|Description|
|-|-|
|🔍 Define|Pulls up a dictionary definition of the inputted word.|
|🗑️ DownClear|Empties your user download directory.|
|💰 ExpenceTracker|Tracks expenses in a CSV file.|
|🎱 Magic Eight Ball|A magic eight ball in your command line.|
|📶 NetInf|Shows information about your network.|
|📜 Scripts|A menu to show all of the scripts.|
|💤 Shutdown Tool|A program that sets up a shutdown command.|
|💽 USBackup|Backup a directory to a USB drive.|
